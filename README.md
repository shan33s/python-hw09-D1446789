# python-hw09-D1446789

程式用途
本程式用來整理「桌遊體驗」與「電影欣賞」兩場活動的原始報名文字。它會先保留原始字串，接著移除半形空白、轉成小寫並依逗號拆分為 list（保留重複與順序），再轉成 set 去除同場重複報名，透過交集、聯集與差集分析參加重疊與單場參加者，
並使用 dict 計算各場去重人數、總不重複人數、報名人次與應收金額（桌遊每人 120 元、電影每人 80 元）。

問題一：桌遊串列有 4 筆卻算 3 人？拆成 list 與轉成 set 的保留與失去
在測試一中，桌遊原始資料整理成 ["amy", "ben", "amy", "cora"] 共有 4 個元素，但 "amy" 出現了兩次。主辦規則是「同一人在同一場活動重複出現
，只算一位參加者、只收一次該場費用」，所以實際參加桌遊的人只有 amy、ben、cora 共 3 人，計費時必須以去重後的 3 人為準。

問題二：測試三只有 3 位不同的人，為什麼是 6 人次、總應收仍是 600 元？
在測試三中，桌遊與電影去重後的名單完全一樣，都是 {"amy", "ben", "cora"}（各 3 人）。
